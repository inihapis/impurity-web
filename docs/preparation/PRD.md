# Product Requirements Document (PRD)

# IMPURITY — Official Website Platform

### Draft v0.2 (Condensed)

---

# 1. Product Overview

## Product Type

Official band website + media/archive platform.

## Core Identity

IMPURITY diposisikan bukan hanya sebagai band deathcore, tetapi sebagai cultural dan creative entity.

Website berfungsi sebagai:

- pusat identitas digital,
- media arsip,
- platform editorial,
- release hub,
- dan ruang campaign/collaboration yang tetap berakar pada identitas band.

## Vision

Membangun platform digital yang:

- merepresentasikan identitas IMPURITY secara kuat,
- menjaga keberlangsungan brand di luar release cycle,
- dan menjadi long-term archive serta creative ecosystem band.

---

# 5. Visual & Tone Direction

## Visual Identity

- monochrome-first,
- editorial-inspired,
- cinematic atmosphere,
- typography-driven,
- restrained motion system.

## Campaign System

Setiap release/campaign dapat memiliki:

- accent color,
- visual texture,
- typography variation,
- thematic atmosphere sendiri.

Namun shell utama website tetap konsisten.

## Tone

- reflective,
- atmospheric,
- human,
- grounded,
- culturally aware.

## Avoid

- generic deathcore aesthetic,
- excessive glitch,
- chaotic UI,
- overdesigned experience.

# 7. Content Strategy

## Sustainability Principle

Website harus tetap aktif meskipun:

- tidak ada release baru,
- tidak ada gigs,
- atau band sedang low activity.

## Sustainable Content Types

- quick notes,
- archive drops,
- rehearsal photos,
- visual scraps,
- playlist/recommendation updates,
- behind-the-scenes fragments.

## Editorial Direction

Konten harus:

- grounded,
- authentic,
- readable,
- dan tidak berubah menjadi media portal umum.

---

# 8. UX & Responsive Strategy

## Design Approach

> Mobile-first with desktop-enhanced immersive experience.
> 

## Mobile Priorities

- fast loading,
- readability,
- smooth navigation,
- efficient motion,
- thumb-friendly interaction.

## Desktop Role

Desktop menjadi:

- immersive exploration space,
- editorial reading environment,
- archive browsing experience.

## Motion Philosophy

Motion digunakan untuk:

- pacing,
- atmosphere,
- transition enhancement.

Bukan gimmick utama.

## Avoid

- excessive animation,
- autoplay media,
- hover-dependent UX,
- heavy cinematic overload.

---

# 9. Technical Direction

## Frontend Stack

- Next.js
- Tailwind CSS
- Framer Motion (light usage)

## Content System

- MDX-based
- static-first architecture
- optional Decap CMS

## Content Structure

Disarankan sejak awal memiliki:

- content schema,
- reusable MDX components,
- metadata standard,
- tagging system.

# 13. Non-Goals (MVP)

Belum diprioritaskan:

- forum/community system,
- marketplace,
- heavy 3D,
- complex authentication,
- overly experimental interactions,
- autoplay music,
- large-scale portal structure.
