# Media & Asset Guide

Panduan ini mengatur penggunaan aset visual seperti gambar, banner, dan logo di dalam website.

## 1. Hero Image / Banner Mobile vs Desktop
- **Rasio & Proporsi**: Hero image diformat sedemikian rupa agar personel tidak terpotong lebih dari 10% di sisi kiri/kanan saat dilihat di layar HP (Portrait).
- **Aturan Kosong**: Bagian atas/bawah yang kosong pada layar mobile akan otomatis terisi oleh gradasi abu-abu gelap ke hitam (*dark background*) agar gambar menyatu secara natural.
- **Saran Aset**: Gunakan resolusi tinggi (min. 1920x1080) landscape. Sistem akan mengatur *object-contain* di mobile dan *object-cover* di desktop.

## 2. Cover Album / Artwork (Discography)
- **Rasio**: Harus persis **1:1 (Persegi)**.
- **Resolusi**: Rekomendasi 800x800 px s/d 1200x1200 px.
- **Dampak Visual**: Cover akan ditampilkan sebagai kartu persegi. Jika rasionya tidak sama, gambar akan terpotong paksa (*crop center*).

## 3. Foto Artikel / Journal
- **Rasio**: Rekomendasi **16:9 (Landscape)**.
- **Visual**: Foto-foto ini digunakan sebagai thumbnail. Hindari meletakkan teks penting di pojok-pojok gambar.

## 4. Logo & Press Kit
- Jangan letakkan file berukuran raksasa langsung di dalam sistem website.
- Arahkan media partner ke folder **Google Drive** yang resmi. Pastikan link `mediaKitUrl` dan `logoPackUrl` diubah sesuai folder Drive yang aktif.
